# <CODE> campaign

Copy this folder to `<workspace>/campaigns/<CODE>/` (setup.sh puts a copy at `<workspace>/campaigns/_template`). Folders: brief · copy (versioned rounds, never overwritten) · master-image · figma · translations · video (plates, audio, layers, out) · exports.
File naming follows the brief: `<CODE>_<WxH>_<Static|Motion>_<LANG>_v<N>`.
